# Reservations Page Override

## Purpose
Minimize booking errors while exposing the fields front-office staff need to operate a hotel.

## Primary flow
Guest identity → stay dates and room → occupancy → rate/meal plan/channel → payment status → notes.

## Interaction
- Validate departure after arrival.
- Keep booking search visible above the reservation list.
- Use explicit payment status text; never rely on color alone.
- Keep cancellation/removal actions secondary.
