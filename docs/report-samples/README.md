# OliTechs generated report samples

Every document in this directory was generated from synthetic fixtures by `npm run samples:reports`. No live property, guest, receipt or staff records were used. The `.pdf` and `.xlsx` files cover Sales Summary, Sales Report, Stock Control, Monthly Sales by Item, Monthly Sales by Category, Monthly Sales by Shift and Sales by Payment Type. Each report has PDF and Excel output. `manifest.json` records output names and byte sizes.

The PNG files under `screenshots/` are rendered pages from the generated Sales Summary and Stock Control PDFs. They show the new data-native document layout, not a browser screenshot of the application. A genuine screenshot of the former screen-print output was not available from an authenticated before-change session and is intentionally not fabricated. Desktop/tablet download and print-preview interaction therefore still needs authenticated browser verification.
