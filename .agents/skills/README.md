# Emil Kowalski UI skills

Selected web-relevant Agent Skills from [emilkowalski/skills](https://github.com/emilkowalski/skills), stored project-locally under `.agents/skills/`.

Included skills cover animation design, choreography, animation reviews and performance, motion opportunity audits, gestures, Apple-inspired interface principles, UI library selection, prototyping, mobile web polish, edge-case UI testing, and Sonner guidance.

React Native/Expo and Swift-specific skills are intentionally excluded because this repository is a Vite + React web application.

These files are instructions for compatible coding agents. They do not add runtime dependencies or change application behavior by themselves.
